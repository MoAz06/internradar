## How to read this

- **Status** is what the careers page said on the Checked date. Windows move, open the link before you plan around it.
- **Process** is only what the company states, or what a candidate reported on the company page. Candidate reports say so and carry a month.
- **Re-apply** is the company's own rule for applying again after a rejection. It is the column that costs people a year when they do not know it.
- **Checked** older than three months: verify it yourself, then send a PR with the new date.

## The site

[internradar.eu](https://internradar.eu) is built from `site/` (Next.js, TypeScript, static export) and deployed by GitHub Actions on every push to `master`. All company data lives in `site/data/`, one file per country. The tables in this README and the pages in `companies/` are generated from it, so edit the data file and run `npm run gen` instead of editing them by hand.

```
cd site && npm install
npm run gen   # rewrite README tables and companies/*.md
npm run dev   # site on localhost:3000
```
